# Phthalo Green — Complete Documentation

A publication-ready academic plotting style for matplotlib, with an extensible
theme system, helper APIs for Seaborn and Plotly, a figure-export layer, a
color-utility toolkit, and a command-line interface.

**Version:** 0.1.1
**Python:** ≥ 3.10 (code is 3.9-compatible via `from __future__ import annotations`)
**Core dependency:** `matplotlib` only. Seaborn / Plotly / pandas are optional.

## 1. Quick Start

```python
import phthalo_green as pg

# Three ways to apply the style:

# 1. One-liner (applies rcParams globally)
pg.apply_style(preset="thesis")

# 2. Figure helper (applies style + creates figure in one call)
fig, ax = pg.subplots(preset="thesis")
ax.plot([0, 1, 2], [1, 4, 2], label="Model A")
ax.plot([0, 1, 2], [2, 1, 3], label="Model B")
ax.legend()
pg.export_figure(fig, "figures/my_first_plot")

# 3. Context manager (auto-restore on exit)
with pg.styled("journal"):
    fig, ax = plt.subplots()
    ax.scatter([1, 2, 3], [4, 5, 6])
```

Your figure now uses:
- Dark charcoal text (`#263238`)
- Light warm background (`#FAFBFA`)
- Phthalo green palette as the color cycle
- Serif fonts with STIX math
- Publication-ready line widths, grid, spines

## 2. Installation

### From source (development)

```bash
git clone https://github.com/yourname/phthalo-green.git
cd phthalo-green
uv sync --extra dev        # or: pip install -e ".[dev]"
```

### As a package

```bash
pip install phthalo-green                  # core (matplotlib only)
pip install "phthalo-green[seaborn]"       # + seaborn adapter
pip install "phthalo-green[plotly]"        # + plotly template support
pip install "phthalo-green[gallery]"       # + gallery example deps
pip install "phthalo-green[dev]"           # + pytest, ruff
```

### Vendoring (single-file copy-paste)

If you want zero packaging, just copy `src/phthalo_green/style.py` into your
project and import it directly:

```bash
cp src/phthalo_green/style.py myproject/phthalo_green.py
```

```python
# myproject/phthalo_green.py  — standalone, only needs matplotlib
from phthalo_green import apply_style, subplots, export_figure
```

Vendoring works because `style.py` is fully self-contained.

### Extras reference

| Extra      | Adds                        | Needed for                          |
|------------|-----------------------------|-------------------------------------|
| `seaborn`  | `seaborn`                   | `apply_seaborn_style()`             |
| `plotly`   | `plotly`                    | `apply_plotly_theme()`              |
| `gallery`  | `wordcloud`, `pandas`, ...  | running `examples/02_gallery.py`    |
| `dev`      | `pytest`, `ruff`            | developing / testing                |

## 3. Project Scaffold (Recommended Layout)

For a thesis, paper, or long-running research project:

```
my-project/
├── figures/                    # exported figures go here
│   ├── 01_time_series.pdf
│   ├── 01_time_series.png
│   └── thesis.mplstyle         # generated by write_mplstyle()
├── scripts/
│   ├── common.py               # shared style setup
│   ├── fig_01_time_series.py
│   ├── fig_02_confusion_matrix.py
│   └── batch_export.py
├── data/
├── phthalo_green.py            # optional: vendored style.py
├── pyproject.toml
└── README.md
```

### `scripts/common.py` — shared style bootstrap

```python
"""Import once at the top of every figure script."""
import matplotlib.pyplot as plt
import phthalo_green as pg

PRESET = "thesis"          # or "journal", "single_column", ...
THEME  = "phthalo_green"   # or "indigo", or your own registered theme

def new_figure(**kwargs):
    return pg.subplots(preset=PRESET, theme=THEME, **kwargs)

def save(fig, basename):
    return pg.export_figure(fig, f"figures/{basename}",
                            formats=("pdf", "png"), png_dpi=600)
```

### `scripts/fig_01_time_series.py`

```python
from common import new_figure, save

fig, ax = new_figure()
ax.plot([1, 2, 3, 4], [10, 14, 13, 17], lw=2, label="Treatment")
ax.fill_between([1, 2, 3, 4], [9, 13, 12, 16], [11, 15, 14, 18],
                alpha=0.2, label="95% CI")
ax.set_xlabel("Week")
ax.set_ylabel("Outcome (mm)")
ax.legend()
save(fig, "fig_01_time_series")
```

### `scripts/batch_export.py` — regenerate every figure in one command

```python
import glob, runpy, sys

for script in sorted(glob.glob("scripts/fig_*.py")):
    print(f"→ {script}")
    runpy.run_path(script, run_name="__main__")
print("All figures exported.")
```

## 4. Style Presets

A **preset** controls *sizing* — font size, figure dimensions, line width,
marker size. It says nothing about color.

```python
pg.apply_style(preset="journal")
```

| Preset          | font_size | figsize (in)  | line_width | marker_size | Typical use                |
|-----------------|-----------|---------------|------------|-------------|----------------------------|
| `thesis`        | 10.0      | 6.5 × 4.2     | 2.0        | 5.0         | A4 thesis chapter figures  |
| `journal`       | 9.0       | 6.3 × 4.0     | 1.8        | 4.5         | Two-column journal paper   |
| `presentation`  | 13.0      | 10.0 × 6.0    | 2.5        | 7.0         | Slides / beamer            |
| `single_column` | 8.5       | 3.4 × 2.6     | 1.6        | 4.0         | Single journal column      |
| `double_column` | 9.0       | 7.0 × 4.2     | 1.8        | 4.5         | Full journal width         |

### Override any preset value inline

```python
pg.apply_style(preset="thesis", font_size=11, figure_width=5.0)
```

### Create your own preset at runtime

```python
pg.STYLE_PRESETS["my_venue"] = {
    "font_size": 8,
    "figure_width": 3.4,
    "figure_height": 2.5,
    "line_width": 1.4,
    "marker_size": 3.5,
}
pg.apply_style(preset="my_venue")
```

### Inspect a preset

```python
print(pg.get_preset("journal"))
# {'font_size': 9, 'figure_width': 6.3, 'figure_height': 4.0,
#  'line_width': 1.8, 'marker_size': 4.5}
```

## 5. Colors and Palettes

### 5.1 Color-name constants

Friendly aliases for ramp roles — each one re-resolves to the active
theme's color for that role:

```python
pg.PHTHALO_GREEN          # '#123524'  → role "primary"  (anchor)
pg.DEEP_PHTHALO_GREEN     # '#0B2418'  → role "dark"     (darkest step)
pg.MEDIUM_PHTHALO_GREEN   # '#176B45'  → role "medium"   (mid-tone)
pg.EMERALD_GREEN          # '#2E8B57'  → role "accent"
pg.LIGHT_GREEN            # '#72A98F'  → role "light"
pg.PALE_GREEN             # '#C7DED3'  → role "pale"     (lightest step)
```

> These are **live** — after `set_theme("indigo")` they re-resolve to the
> new theme's equivalents. Use attribute access (`pg.PHTHALO_GREEN`), not
> `from phthalo_green import PHTHALO_GREEN` if you plan to switch themes.
> For any other role use `pg.get_color("ochre")` or `pg.PALETTE["ochre"]`.

### 5.2 Palette roles (keys in `PALETTE`)

| Role / key          | Meaning                             |
|---------------------|-------------------------------------|
| `dark`              | Darkest shade of the main hue       |
| `primary`           | The anchor color of the theme       |
| `medium`            | Mid-tone                            |
| `accent`            | Light accent of the main hue        |
| `light`             | Light fill / background accent      |
| `pale`              | Palest tint                         |
| `blue_green`, `blue`| Cool supporting accents             |
| `ochre`, `rust`     | Warm supporting accents             |
| `plum`              | Purple supporting accent            |
| `charcoal`          | Main text / dark neutral            |
| `slate`             | Secondary text / muted              |
| `gray`, `gray_light`| Lighter neutrals                    |
| `background`        | Figure & axes facecolor             |
| `white`             | Pure white                          |

### 5.3 The four palette kinds

```python
pg.CATEGORICAL          # 10 colors, default prop_cycle
pg.CATEGORICAL_GREEN    # 6 greens only (monochrome variant)
pg.SEQUENTIAL           # 8 colors, dark → light (heatmap ramps)
pg.DIVERGING            # 8 colors, dark → pale → warm (two-endpoint data)
```

### 5.4 Accessors

```python
pg.get_color("primary")                 # '#123524'
pg.get_color("rust", theme="indigo")    # query another theme's color
pg.get_palette("categorical", n=4)      # first 4 categorical colors
pg.get_palette("sequential")            # full 8-step ramp
```

**Important:** `get_palette` returns *hand-picked* subsets for small `n`
(≤ palette length), not interpolated samples — so `get_palette("categorical", 3)`
gives 3 visually distinct colors, not 3 similar ones.

### 5.5 Colormaps

```python
cmap = pg.get_cmap("sequential")       # Phthalo ramp
cmap = pg.get_cmap("diverging", n=12)  # resample to 12 levels
cmap = pg.SEQUENTIAL_CMAP              # same as get_cmap("sequential")
cmap = pg.DIVERGING_CMAP
cmap = pg.CATEGORICAL_CMAP             # discrete colormap of categorical
```

Named matplotlib registrations (usable as `cmap=` strings after theme is set):

```python
cmap="phthalo_green"          # sequential (also image.cmap default)
cmap="phthalo_green_diverging"
cmap="phthalo_green_categorical"
cmap="indigo"                 # each registered theme gets its own names
cmap="indigo_diverging"
```

### 5.6 Example: styled scatter with a diverging colormap

```python
import numpy as np
fig, ax = pg.subplots()
data = np.random.randn(10, 10)
im = ax.imshow(data, cmap=pg.get_cmap("diverging"), aspect="auto")
fig.colorbar(im, ax=ax, label="z-score")
pg.export_figure(fig, "figures/heatmap")
```

## 6. Themes — The Extensibility System

A **theme** is the *color identity*: base colors, all four palettes, fonts.
The design principle: **you only supply colors; everything else derives.**

### 6.1 Built-in themes

```python
pg.list_themes()          # ['phthalo_green', 'indigo', ...]
pg.active_theme().name    # 'phthalo_green'
pg.describe_theme("indigo")
# {'name': ..., 'label': ..., 'description': ...,
#  'colors': {...}, 'palettes': {...},
#  'serif': [...], 'sans': [...], 'math_fontset': ...,
#  'colormaps': {...}}
```

### 6.2 Three ways to define a theme's colors

#### (a) One anchor color (auto-derives everything)

```python
pg.register_palette("brand_blue", "#1A4A9E")
```

From one hex, the library builds:
- a dark→light ramp (`dark`, `primary`, `medium`, `accent`, `light`, `pale`)
- supporting accents (ochre, rust, plum, blue_green, blue)
- neutrals (charcoal, slate, grays, background)
- sequential + diverging ramps
- all colormaps

#### (b) A full ordered ramp (dark → light)

```python
pg.register_palette("sunset", [
    "#3B0A1B", "#7B1E3C", "#C43D4F",
    "#E8896B", "#F5C4A1", "#FBE7D3",
])
```

#### (c) A full dict (total control)

```python
pg.register_palette("company", {
    "dark":       "#0D1B2A",
    "primary":    "#1B6CA8",
    "medium":     "#3E92CC",
    "accent":     "#89CFF0",
    "light":      "#C9E7F5",
    "pale":       "#EAF5FB",
    # optional: supply any of these to override auto-derivation
    "ochre":      "#A58A45",
    "rust":       "#9A5B4A",
    "charcoal":   "#1C1C1E",
    "background": "#FCFCFD",
})
```

Keys you omit are auto-derived from what you supply.

#### Extra knobs on `make_theme`

```python
theme = pg.make_theme(
    "my_theme", "#1A4A9E",
    categorical=["#1A4A9E", "#A58A45", "#9A5B4A", "#2E8B57"],  # override
    sequential=["#0A1A33", "#1A4A9E", "#89CFF0", "#EAF5FB"],    # override
    diverging=["#8C2F39", "#E0B8B8", "#F5F0E8", "#2A6F97"],
    serif=["Charter", "Georgia", "Times New Roman"],
    sans=["Helvetica", "Arial"],
    label="Company Brand",
    description="Internal reporting palette.",
)
pg.register_theme(theme, override=True)
```

### 6.3 Switching themes

```python
pg.set_theme("indigo")            # global switch + applies rcParams
pg.use_theme("indigo")            # alias

with pg.with_theme("indigo"):     # temporary, auto-reverts
    fig, ax = pg.subplots()
    ax.plot(y)

fig, ax = pg.subplots(theme="indigo")   # applies the theme globally
                                        # (same as set_theme + apply_style);
                                        # use with_theme() above for a
                                        # temporary switch

with pg.styled(theme="indigo"):         # context manager: restores BOTH
    fig, ax = plt.subplots()            # rcParams and theme on exit
```

> **Note:** matplotlib styling is process-global (`rcParams`), so
> `apply_style(..., theme=...)`, `subplots(..., theme=...)` and
> `figure(..., theme=...)` all switch the *active theme* until you switch
> back. When you need isolation, use `with pg.with_theme(...)` or
> `with pg.styled(...)`, which restore state on exit.

### 6.4 Live palette containers (important design detail)

`PALETTE`, `CATEGORICAL`, `SEQUENTIAL`, `DIVERGING` are mutated **in place**
on theme switch:

```python
from phthalo_green import PALETTE   # safe: same dict object forever
print(PALETTE["primary"])           # '#123524'

pg.set_theme("indigo")
print(PALETTE["primary"])           # '#...' (now indigo's primary)
```

Color **constants** (`PHTHALO_GREEN`, `SEQUENTIAL_CMAP`, …) resolve through
`__getattr__`, so always use attribute access:

```python
# ✅ follows the active theme
pg.PHTHALO_GREEN
pg.SEQUENTIAL_CMAP

# ❌ frozen at import time — will NOT follow theme switches
from phthalo_green import PHTHALO_GREEN
```

### 6.5 Defining a theme as data (recommended for projects)

Put your palette in a config file so non-Python tools can read it too:

```python
# themes/my_brand.py
import phthalo_green as pg

BRAND = pg.make_theme(
    "my_brand",
    {"dark": "#102030", "primary": "#1B6CA8", "medium": "#3E92CC",
     "accent": "#89CFF0", "light": "#C9E7F5", "pale": "#EAF5FB"},
    label="My Brand",
)
pg.register_theme(BRAND, override=True)
```

```python
# scripts/common.py
import phthalo_green as pg
import themes.my_brand  # registers on import
pg.set_theme("my_brand")
```

## 7. Matplotlib Integration

### 7.1 `apply_style`

```python
pg.apply_style(
    preset="thesis",
    theme="phthalo_green",
    font_size=10,           # optional overrides
    figure_width=6.5,
    figure_height=4.2,
    line_width=2.0,
    marker_size=5.0,
    font_family=None,       # "serif" (default) or "sans-serif"
    rc={"axes.grid": False},           # arbitrary extra rcParams, applied last
)
```

> All arguments are **keyword-only** — `pg.apply_style("thesis")` raises.

### 7.2 What it sets (rcParams summary)

| Group     | Keys |
|-----------|------|
| Figure    | `figure.figsize`, `figure.dpi`, `figure.facecolor` |
| Font      | `font.family`, `font.size`, `font.serif`, `font.sans-serif`, `mathtext.fontset` |
| Axes      | `axes.grid`, `axes.edgecolor`, `axes.facecolor`, `axes.labelsize`, `axes.titlesize`, `axes.prop_cycle`, `axes.linewidth`, `axes.xmargin`/`ymargin`, `axes.titlecolor`, `axes.labelcolor` |
| Ticks     | `xtick.labelsize`, `xtick.color`, `xtick.major/minor.size/width`, `xtick.direction`, (same for y) |
| Lines     | `lines.linewidth`, `lines.markersize`, `lines.solid_capstyle` |
| Grid      | `grid.color`, `grid.linewidth`, `grid.alpha` |
| Legend    | `legend.frameon=False`, `legend.labelcolor`, `legend.fontsize`, `legend.handlelength` |
| Image     | `image.cmap` = theme's sequential colormap **name** |
| Export    | `savefig.dpi=300`, `savefig.facecolor`, `bbox_inches` via export helper, `pdf.fonttype=42` (embedded fonts), `svg.fonttype='none'` (editable text), `ps.fonttype` |
| Spines    | `axes.spines.top/right = False` (via preset behavior) |
| Minor     | minor ticks visible by default |

### 7.3 Axis helpers

```python
fig, ax = pg.subplots()

# grid + optional spine removal (per-axes, not global)
pg.style_axis(ax, grid=True, remove_top_right_spines=True)

# or manually
pg.despine(ax, spines=("top", "right"), grid=True)

# legend without frame
ax.legend()
pg.style_legend(ax.get_legend(), frameon=False, title="Condition")
```

### 7.4 `preset_rc()` — get the dict, don't mutate anything

Useful for `plt.style.use()` or sharing config:

```python
rc = pg.preset_rc("journal", font_size=8)
with plt.rc_context(rc):
    fig, ax = plt.subplots()
    ax.plot([1, 2, 3])
```

### 7.5 `styled()` context manager

```python
with pg.styled("journal", font_size=11, theme="indigo"):
    fig, ax = plt.subplots()
    ...
# rcParams AND theme are restored on exit
```

### 7.6 Writing an `.mplstyle` file (for collaborators)

```python
pg.write_mplstyle("figures/thesis.mplstyle", preset="thesis",
                  theme="phthalo_green")
```

A collaborator who doesn't install your package can then do:

```python
import matplotlib.pyplot as plt
plt.style.use("figures/thesis.mplstyle")
```

### 7.7 LaTeX integration

```python
pg.configure_latex(use_tex=True)          # switch mathtext → real LaTeX
pg.configure_latex(use_tex=True,
                   preamble=[r"\usepackage{amsmath}"])
```

### 7.8 Word fonts / resolved serif

```python
pg.resolved_serif_font()   # e.g. 'Times New Roman' on macOS
```

## 8. Other Libraries (Seaborn, Plotly, pandas)

### 8.1 Seaborn

```python
import seaborn as sns
import phthalo_green as pg

pg.apply_seaborn_style(preset="thesis", theme="phthalo_green",
                       palette="categorical")
# Now sns.* plots inherit seaborn objects but Phthalo fonts/colors/grid.

sns.lineplot(data=df, x="t", y="y", hue="model")
sns.boxplot(data=df, x="group", y="value")
```

For **temporary** use, wrap it:

```python
with pg.styled("journal"):
    pg.apply_seaborn_style(theme="indigo")
    sns.heatmap(corr, cmap=pg.get_cmap("diverging"))
```

### 8.2 Plotly

```python
import plotly.express as px
import phthalo_green as pg

# Option A: build the template dict yourself
tmpl = pg.plotly_template("phthalo_green", font_size=12)
fig = px.scatter(df, x="x", y="y", color="grp")
fig.update_layout(template=tmpl)

# Option B: apply + create
tmpl = pg.apply_plotly_theme("indigo", name="my_indigo")
fig = px.line(df, x="t", y="y", template="my_indigo")
```

`plotly_template()` is a **pure dict** — it works even if plotly is not
installed (useful for generating config files). `apply_plotly_theme()`
registers it into `plotly.io.templates` and needs plotly installed.

The template includes `colorway` (categorical colors), fonts, axis/grid
styling, and a matching `layout.colorscale.sequential` / `.diverging`.

### 8.3 pandas + matplotlib (no extra lib needed)

```python
df.plot(kind="bar", ax=ax)              # after pg.apply_style()
df.plot(subplots=True, figsize=(9, 6))  # preset sizing wins
```

Recommended order: apply style first, then plot:

```python
fig, axes = pg.subplots(preset="thesis", nrows=2, ncols=2)
df.plot(ax=axes[0, 0], title="A")
```

## 9. Exporting Publication Figures

### 9.1 `export_figure` (primary API)

```python
paths = pg.export_figure(
    fig,
    "figures/01_time_series",        # basename — extension appended, not replaced
    formats=("pdf", "png"),          # vector + raster combo
    png_dpi=600,                     # raster quality
    vector_dpi=300,                  # pdf rasterization dpi (fonts only; stays vector)
    transparent=False,               # True for slides / dark backgrounds
    bbox_inches="tight",             # crop whitespace
    close=True,                      # close figure after saving (batch jobs)
    metadata={"Title": "Figure 1", "Author": "A. Researcher"},
)
# → [Path('figures/01_time_series.pdf'), Path('figures/01_time_series.png')]
```

Supported formats: `pdf`, `svg`, `eps`, `png`.

**Filename safety:** dots in the *basename* are preserved —
`"results.v2"` becomes `results.v2.pdf`, not `results.pdf`.

### 9.2 `save_publication_figure` (single-file convenience)

```python
pg.save_publication_figure(
    fig, "figures/paper_fig3.pdf",
    transparent=False, dpi=600, metadata={"Creator": "phthalo-green"},
)
```

### 9.3 `export_dpi` — know your defaults

```python
pg.export_dpi("png")   # 600
pg.export_dpi("pdf")   # 300
pg.export_dpi("svg")   # 300
pg.export_dpi("eps")   # 300
```

### 9.4 Conventions by output target

| Target              | formats           | dpi    | transparent | notes                     |
|---------------------|-------------------|--------|-------------|---------------------------|
| Journal (PDF)       | `("pdf",)`        | —      | False       | fonts embedded (fonttype 42) |
| Journal (raster)    | `("png",)`        | 600    | False       |                           |
| Thesis figure       | `("pdf","png")`   | 600    | False       | both for LaTeX + archive  |
| Slides (PPT/Keynote)| `("png",)`        | 300    | **True**    | dark slide backgrounds    |
| Web / README        | `("png",)`        | 150    | False       |                           |
| Vector editing      | `("svg",)`        | —      | False       | open in Illustrator/Inkscape |
| Legacy journals     | `("eps",)`        | —      | False       |                           |

### 9.5 Batch export pattern

```python
import matplotlib.pyplot as plt

for i in range(n_experiments):
    fig, ax = pg.subplots(theme="phthalo_green")
    plot_experiment(ax, results[i])
    pg.export_figure(fig, f"figures/exp_{i:03d}", formats=("png",),
                     close=True)   # close=True prevents memory blow-up
plt.close("all")
```

## 10. Color Utilities

All functions accept anything matplotlib accepts: hex string, named color,
RGB tuple, RGBA tuple.

```python
pg.to_hex("#123456")                 # normalize any input → '#123456'
pg.to_hex((0.1, 0.2, 0.3))           # → '#1a334c' (always lowercase)

pg.mix("#000000", "#FFFFFF", 0.5)    # → '#808080'
pg.lighten("#123524", 0.3)           # → '#597266' (toward white)
pg.darken("#123524", 0.2)            # → '#0e2a1d' (toward black)
pg.shift_hue("#123524", 30)          # rotate hue by 30°
pg.css_rgba("#123524", 0.5)          # → 'rgba(18, 53, 36, 0.5000)'
pg.with_alpha("#123524", 0.4)        # → (0.0706, 0.2078, 0.1412, 0.4)

pg.relative_luminance("#FFFFFF")     # 1.0
pg.relative_luminance("#000000")     # 0.0
pg.contrast_ratio("#123524", "#FAFBFA")  # WCAG ratio, aim ≥ 4.5
```

### Use case 11 — Contrast check before publishing

Check the colors that actually carry meaning (text and markings) against
the figure background — WCAG AA needs ≥ 4.5:1 for body text:

```python
import phthalo_green as pg

theme = pg.get_theme()
bg = theme.colors["background"]
for name in ("charcoal", "slate", "primary", "medium", "ochre"):
    ratio = pg.contrast_ratio(theme.colors[name], bg)
    flag = "OK " if ratio >= 4.5 else "low"
    print(f"{name:10s} {ratio:5.2f}:1  {flag}")
```

Body text (`charcoal`) needs ≥ 4.5:1; ticks and line markings need only
≥ 3:1 (WCAG non-text). Fill colors (`white`, `gray_light`, `pale`) are
intentionally close to the background, so exclude them from the check.

## 16. Troubleshooting & FAQ

**Q: `apply_style()` says "positional argument not allowed"?**
A: All arguments are keyword-only. Use `pg.apply_style(preset="thesis")`.

**Q: `ax.scatter()` raises `TypeError: unhashable type: 'LinearSegmentedColormap'`?**
A: You set `image.cmap` to a Colormap object. Always set it to the
*name* (`"phthalo_green"`), which `apply_style()` does correctly.

**Q: Overwriting the cmap warning when switching themes repeatedly?**
A: Fixed in 0.1.1 — registration tracks already-registered names and only
re-registers with `force=True`. If you see it, you registered manually
without `force`.

**Q: `from phthalo_green import PALETTE` — is it stale after `set_theme`?**
A: No. `PALETTE` is a live dict mutated in place. But *constants*
(`PHTHALO_GREEN`, `SEQUENTIAL_CMAP`) are frozen at import — use attribute
access (`pg.PHTHALO_GREEN`).

**Q: Plotly import fails?**
A: `plotly_template()` needs no plotly. `apply_plotly_theme()` does. Install
`phthalo-green[plotly]`.

**Q: Where did my text colors go in grayscale?**
A: Export vector (`.pdf`) with fonts embedded — the style sets
`pdf.fonttype=42`, so text stays text. For raster, use 600 dpi.

**Q: Dots in my filename get eaten?** (`results.v2` → `results.pdf`)
A: Fixed in 0.1.1. `export_figure` appends extensions rather than
replacing them.

**Q: `ax.tick_params(minor=...)` raises?**
A: This style doesn't support that. Use `ax.minorticks_on()` /
`ax.minorticks_off()`.

**Q: How do I reset to defaults?**
A: `pg.set_theme("phthalo_green")` + `pg.apply_style()`, or in a notebook
restart and re-import (rcParams are process-global).

**Q: Does the original Phthalo Green palette ever change?**
A: No. It's asserted byte-for-byte in `tests/test_style.py::test_default_palette_is_unchanged`.

**Q: Can I use this without installing the package?**
A: Yes — vendor `style.py` (see [Installation](#2-installation)) or use
`write-style` / `plt.style.use()` with a `.mplstyle` file.

## 17. Migration Guide (0.1.0 → 0.1.1)

| 0.1.0 | 0.1.1 |
|-------|-------|
| fixed palette | **theme system** (new); default unchanged |
| `apply_style(preset)` positional | `apply_style(preset=...)` keyword-only |
| — | `set_theme`, `register_palette`, `with_theme` |
| — | `get_color`, `get_palette`, `get_cmap` accessors |
| — | `preset_rc`, `styled`, `write_mplstyle` |
| — | CLI (`phthalo-green`, `python -m phthalo_green`) |
| — | color utils (`mix`, `lighten`, `contrast_ratio`, …) |
| `export_figure` bug (dots in filenames) | fixed; format-aware dpi; metadata |
| single palette | `PHTHALO_GREEN`, `SEQUENTIAL_CMAP` etc. are live |

**Backward compatible:** existing scripts using `PALETTE`, `CATEGORICAL*`,
`apply_style`, `style_axis`, `export_figure`, `set_theme` keep working.

Version appears in `pyproject.toml`, `__init__.__version__`, and CLI `-V`.

## 18. Development Commands

```bash
# Lint
python3 -m ruff check src tests examples conftest.py
# (or with uv: uv run ruff check src tests examples)

# Test
python3 -m pytest -q                    # conftest.py puts src/ on path
# 33 passed, 1 skipped (plotly not installed)

# Run examples
PYTHONPATH=src python3 examples/01_minimal.py
PYTHONPATH=src python3 examples/02_gallery.py --preset thesis
PYTHONPATH=src python3 examples/03_themes.py

# CLI
PYTHONPATH=src python3 -m phthalo_green themes
PYTHONPATH=src python3 -m phthalo_green preview figures/preview

# With uv (CI does this)
uv sync --extra gallery --extra plotly --extra dev
uv run pytest -q
uv run ruff check src tests examples
uv build
```

CI (`.github/workflows/ci.yml`) runs: sync → lint → test → all three
examples → CLI smoke → `uv build`.
